# V4.2 — виправлення сценарію та таймінгів

## Основне виправлення

V4.1 помилково класифікувала рядок `Сцена N (час): ... Субтитр: «...»` як режисерську вказівку. Через це весь рядок разом із субтитром відкидався. Якщо весь сценарій складався з таких рядків, рендерер переходив на резервний `headline` і створював коротке відео з повтором загальної теми.

V4.2 розбирає storyboard до очищення технічних приміток, витягує текст субтитрів і текстові написи з лапок, формує окрему сцену для кожного пункту ТЗ та використовує часові інтервали з ТЗ.

## Додатково

- Підтримано `Субтитр` в однині та інші маркери тексту для глядача.
- Технічний блок `Візуальні примітки` лишається поза аудиторним текстом.
- Фінальна сцена storyboard не замінюється стандартним CTA.
- Прибрано дублювання коротких новинних субтитрів у двох картках.
- Збережено старий алгоритм для звичайного сценарію без розбиття на сцени.
- Тестовий пакет: 29 тестів, включно з повним MP4 Reels на 25 секунд і п'ятьма сценами.
- Контракт `build_video(job, output_path)` і залежності не змінені.
