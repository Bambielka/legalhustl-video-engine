# SENTINEL LAW Motion Engine V3

Автоматичний motion-design рендерер для Instagram Reels і Stories. Візуальна система натхненна наданим референсом із Remotion: світлий редакційний фон, велика чорна типографіка, фіолетові акценти, поетапна поява карток, інфографіка, лічильник сцен, прогрес і текстові блоки в нижній частині кадру.

**Важливо:** цей пакет відтворює візуальну мову Remotion, але сам рендерить кадри через Python + Pillow + FFmpeg. Це свідоме рішення для збереження чинного Python worker і Cloud Video Bridge без Node.js-пакетів та зміни Apps Script.

## Що відрізняється від попередньої версії

- Не статичні слайди: кожна сцена має анімовану появу заголовка, поетапну побудову карток, рухомі акцентні елементи та прогрес.
- Візуальні блоки адаптуються до тексту: правове посилання, документ, строки/числа, дії або загальні ключові тези.
- Основний текст із затвердженого сценарію показується в нижньому caption-блоці. Текст не обрізається мовчки.
- Наявні посилання на статті, частини, пункти показуються лише якщо вони прямо є в сценарії. Генератор не вигадує номери статей чи строки.
- Музика — оригінальний синтезований стереотрек із ритмом, басом та короткими звуковими акцентами.
- Для кожної сцени змінюється композиція; тривалість Reels розраховується з обсягу тексту і часу читання.
- Візуальний стиль Sentinel Law: білий, чорний, фіолетовий. Обличчя користувача не використовується.

## Формат

- 720 × 1280, 30 fps, H.264 + AAC stereo.
- Reels — адаптивна тривалість за сценарієм.
- Stories — 12 секунд.
- Цільовий розмір файлу — до 8.5 MB, із запасом до ліміту Cloud Video Bridge 9 MB.
- У поточній версії немає синтезованого голосу ведучого: є музика й звукові акценти, а затверджений текст виводиться на екран.

## Архітектура не змінюється

Google Sheets → Apps Script → `Video Jobs` → GitHub Actions → `worker.py` → `renderer.py` → FFmpeg → Google Drive → Instagram.

`worker.py`, Apps Script, токен Cloud Video Bridge, URL мосту та GitHub Secrets залишаються без змін. `renderer.py` зберігає функцію `build_video(job, output_path)`, яку викликає чинний worker.

## Файли для оновлення

1. `renderer.py`
2. `requirements.txt`
3. `tests/test_renderer.py`
4. `.github/workflows/render.yml`

`README.md`, `INSTALL_V3.md`, `sample-job.json` і `sample-story.json` — документація та приклади.

## Локальна перевірка

```bash
python -m pip install -r requirements.txt
python -m unittest discover -s tests -v
python renderer.py --job sample-job.json --output sample.mp4
```

`ffmpeg` і шрифт DejaVu Sans мають бути встановлені в системі.

## Межі та редакційна безпека

- Генератор не є юридичним фактчекером. Контент має пройти наявне схвалення та фактчек у Google Sheets до постановки в чергу.
- Візуальні картки можуть виділяти частини сценарію, але не додають нових юридичних тверджень.
- Якщо сценарій надто довгий або MP4 виходить за 8.5 MB, завдання завершується помилкою, а не обрізає зміст.
- Публікацію не запускає сам рендерер; наявні перевірки календаря та Instagram залишаються чинними.
