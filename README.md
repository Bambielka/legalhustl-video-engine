# SENTINEL LAW Motion Engine V4.2

Редакційний motion-design рендерер для Instagram Reels і Stories. V4.2 зберігає чинний контракт Cloud Video Bridge та виправляє обробку сценаріїв, переданих як покадрове ТЗ.

## Що виправлено у V4.2

- Додано розбір структурованих сценаріїв `Сцена N (початок–кінець с): ... Субтитр: «...»`. Субтитри більше не відкидаються разом із режисерськими вказівками.
- Кожна сцена storyboard зберігається окремо. Заголовок сцени береться з явно зазначених у ТЗ написів у лапках, а аудиторний текст — із поля `Субтитр` або іншого підтримуваного текстового маркера.
- Якщо ТЗ містить таймінг сцен, тривалість кожної сцени відповідає вказаному інтервалу. Наприклад, п'ять інтервалів `0–4`, `4–9`, `9–14`, `14–20`, `20–25` дають ролик рівно 25 секунд.
- Для готового storyboard не створюється зайва стандартна фінальна сцена, яка витісняла б змістовний фінал із ТЗ.
- Для коротких новинних сцен прибрано повторення одного й того самого субтитру у двох картках. Повний текст залишається видимим в основній картці.
- Розширено резервні поля для тексту сценарію: `script`, `caption`, `source_text`, `full_text`, `article_text`, `body`, `text`.
- Попередні виправлення V4.1 збережені: 18 композицій, 9 типів відео, безпечна обробка коротких how-to/checklist, сумісність з `worker.py`.

## Формат структурованого ТЗ

Рендерер розуміє звичайний текстовий сценарій і сценарій, розбитий на сцени. Приклад:

```text
Тривалість: близько 25 секунд.
Сцена 1 (0–4 с): Кадр із текстовою заставкою. Субтитр: «Питання для глядача?»
Сцена 2 (4–9 с): На екрані напис «Рішення ухвалено». Субтитр: «Орган ухвалив відповідне рішення».
Сцена 3 (9–14 с): Картка з цифрами «до 1 млрд грн» і «5,5%». Субтитр: «Оголошено фінансові параметри програми».
Сцена 4 (14–20 с): Напис «Механізм ще запускають». Субтитр: «Практична реалізація ще потребує запуску».
Сцена 5 (20–25 с): Картка «Умови? Дата?». Субтитр: «Перевірте офіційні умови перед дією».
Візуальні примітки: використовувати текстові картки.
```

Підтримуються маркери `Субтитр`, `Субтитри`, `Текст диктора`, `Текст для озвучки`, `Голос за кадром`, `Репліка`, `Озвучка`, `Текст на екрані`. Заголовки сцен і технічні примітки не показуються як аудиторний текст. Якщо таймінг не заданий або не розпізнаний, застосовується звичайний адаптивний розрахунок тривалості.

Поля `video_type` не обов'язкове. Якщо воно відсутнє, тип визначається за `topic`, `headline` і текстом сценарію. Для новин доцільно передавати `"video_type": "news"`.

## Дев'ять типів відео

| Внутрішній тип | Призначення | Варіанти композиції |
|---|---|---|
| `news` | Новини та нормативні зміни | Новинний бюлетень, таймлайн |
| `explainer` | Юридичні пояснення | Карта понять, редакційні шари |
| `howto` | Покрокові інструкції | Вертикальні кроки, картки кроків |
| `myth_fact` | Міф / правда | Розділений екран, поетапне розкриття |
| `case` | Судові справи та правові позиції | Таймлайн, судове досьє |
| `checklist` | Переліки документів та умов | Сітка, вертикальний список |
| `comparison` | Порівняння та «було / стало» | Дві колонки, композиція з балансом |
| `qa` | Питання та відповіді | Картка питання, акцент на відповіді |
| `risk` | Помилки та юридичні ризики | Попередження, маршрут ризику |

## Архітектура та сумісність

Google Sheets → Apps Script → `Video Jobs` → GitHub Actions → `worker.py` → `renderer.py` → FFmpeg → Google Drive → Instagram.

Публічний контракт `build_video(job, output_path)` не змінений. `worker.py`, Apps Script, URL Cloud Video Bridge, токен і GitHub Secrets не змінюються. Новий стовпець у Google Sheets не потрібен.

## Вихідний формат

- 720 × 1280, 30 fps.
- H.264 video + AAC stereo audio.
- Reels — адаптивна тривалість для звичайного тексту; для storyboard використовується розпізнаний таймінг сцен.
- Stories — 12 секунд.
- Цільовий розмір MP4 — до 8.5 MB, із запасом до ліміту Cloud Video Bridge 9 MB.
- Музика — оригінальний синтезований стереотрек; голос ведучого не генерується.
- Не використовуються обличчя користувача чи випадкові стокові люди.

## Локальна перевірка

Потрібні Python 3.13, FFmpeg, FFprobe та DejaVu Sans. На Ubuntu:

```bash
sudo apt-get update
sudo apt-get install -y ffmpeg fonts-dejavu-core
python -m pip install -r requirements.txt
python -m py_compile renderer.py worker.py tests/test_renderer.py
python -m unittest discover -s tests -v
python renderer.py --job sample-news-storyboard.json --output sample-news.mp4
```

## GitHub Actions

- `push` до `main` і Pull Request запускають тільки тестовий job.
- `schedule` (кожні 10 хвилин) та `workflow_dispatch` запускають тести, а після їх успіху — окремий job рендерингу черги.
- На звичайний `push` секрети не використовуються і відеозавдання з Google Sheets не забираються.

## Редакційна безпека

- Рендерер не є юридичним фактчекером і не визначає чинність норм.
- Рендерер не додає нових прав, обов'язків, строків, сум або номерів статей.
- Графічні підписи формуються лише з тексту, переданого у сценарії; відсутні факти не домислюються.
- Аудиторний текст зберігається; технічні примітки видаляються до рендерингу.
- Матеріал потрібно переглядати перед публікацією.
